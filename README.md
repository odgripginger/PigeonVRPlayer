# Pigeon Player website

Static website for Pigeon Player, a VR video player from Rosetta Studios.

- [Live website](https://odgripginger.github.io/pigeon-player-website/)
- [Privacy Policy for Meta Horizon Store](https://odgripginger.github.io/pigeon-player-website/privacy.html)

GitHub Pages publishes the root of the main branch. The site uses HTML and CSS with no build step. Open index.html locally to preview edits, then push to main to publish them.
